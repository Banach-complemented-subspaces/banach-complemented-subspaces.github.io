# Public evidence copy

This is a separately prepared copy of recorded verification evidence. Personal
computer paths and account names have been replaced by LEAN_PROJECT, WORKSPACE
and USER_HOME. Author attribution, mathematical proofs, theorem statements,
audit outcomes, timestamps and historical hashes are retained.

The original evidence is preserved separately by the author. This preparation
does not constitute a new Lean audit. Hashes within historical reports still
identify the original files and archives; they do not identify these public
copies. PUBLIC_COPY_SHA256.json records original and public file hashes.
PUBLIC_ARCHIVE_MEMBERS_SHA256.json records member hashes, including nested ZIPs.
Path replacements in audit scripts are placeholders to configure before use.
